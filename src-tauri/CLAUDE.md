# src-tauri

Stop `fanal.exe` before `cargo build`. The linker cannot replace a running binary.

The window is the painted panel in every view. Do not add a transparent band under the lip. That band covers the browser tabs.

A session file holds the conversation. Read status, cwd, or event type only. Do not log, store, or show the rest, and do not commit an agent's own directory.

Claude Desktop keeps one sessions directory per profile. Read every directory. A newer empty one must not hide an older task that is still running.

Codex and ChatGPT are one program. `chatgpt` owns the window and `codex` is the helper. Focusing only `codex` opens nothing.
